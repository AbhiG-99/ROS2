# Exercise 5 — Chaining without being told

Nobody publishes `odom -> camera_link` directly.
Using only the nodes from Exercise 2 (`sensor_mounts`) and Exercise 3
(`figure_eight`) the transform still exists — TF2 **walks the tree** for you.

## How to get it

Terminal 1:

```bash
ros2 run tf2_lessons figure_eight      # publishes odom -> base_link
```

Terminal 2:

```bash
ros2 run tf2_lessons sensor_mounts     # publishes base_link -> laser, base_link -> camera_link
```

Terminal 3:

```bash
ros2 run tf2_ros tf2_echo odom camera_link
```

It prints a valid transform even though no node ever publishes it.

## The path TF2 took (write this in your submission)

```
odom  --(figure_eight, Ex 3)-->  base_link  --(sensor_mounts, Ex 2)-->  camera_link
```

TF2 computed:

```
T(odom -> camera_link) = T(odom -> base_link)  (o)  T(base_link -> camera_link)
```

i.e. it found the shortest parent–child route in the tree, then
**concatenated (multiplied) the intermediate transforms**. This works in
one direction or the other (inverted when walking edges backwards),
which is why intermediate frames never need to be published between
every pair of frames.

You can see this topology in the PDF generated by
`ros2 run tf2_tools view_frames`.
